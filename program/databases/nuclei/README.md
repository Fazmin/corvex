# Bundled Nuclei templates

This directory holds the Tier-1 bundled subset of the
[nuclei-templates](https://github.com/projectdiscovery/nuclei-templates)
library — only templates whose `info.severity` is `critical`, `high`,
or `medium`, or whose tags include `kev`.

The bundle is regenerated by `scripts/refresh-nuclei-bundle.sh`, which
pins the upstream release tag and writes the manifest. Templates are
executed by [crates/corvex-nuclei/](../../../crates/corvex-nuclei/).

**License:** MIT — see [THIRD_PARTY_LICENSES.md](../../../THIRD_PARTY_LICENSES.md)
for the full notice and attribution requirements. Per-template author
credit is preserved in each YAML `info.author` field and emitted with
every finding.

**Full-library opt-in:** end users can fetch the complete template tree
into their local data directory (`%APPDATA%/corvex/nuclei-templates/` on
Windows) via the desktop app — those files are not redistributed here.
